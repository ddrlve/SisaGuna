# SisaGuna

Aplikasi mobile redistribusi makanan untuk UMKM kuliner Indonesia.
Warung, kantin, bakery, dan resto kecil memposting makanan berlebih sebelum
menjadi sampah. Pembeli di sekitar mengambilnya langsung di tempat by app.

Proyek mata kuliah Venture Creation (ENPR6312), BINUS, Kelompok 4 kelas LZ01.
Tema Lingkungan Alam.
